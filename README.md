# HorseRaceSimulator
Coursework

HorseRaceSimulator is a project that simulates horse racing. It consists of two parts: a textual version (Part 1) and a graphical version (Part 2).

## Part 1: Textual Version
The Part 1 folder contains all the code related to the textual version of the horse racing simulator. This version focuses on testing and enhancing the classes Horse and Race. 
It runs a simple racing program on the console. 

## Part 2: Graphical Version
The Part 2 folder contains all the code related to the graphical version of the horse racing simulator. It provides a graphical user interface (GUI) for users to interact with the simulator.
Some important instructions related to running the program are providedon the GUI itself.  

## Getting Started: Follow these steps:
1. Clone this repository to your local machine.
2. Navigate to the desired part of the project (Part1 or Part2) to work with.
Part1:
- Run the Race.java file and it will implement a simple racing program

Part 2: 
- Run the Main.java file and it will implement the full program
